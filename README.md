# Sidekick

Your slightly bossy sidekick for calm focus and clear boundaries.

Built with Enid — a friendly but no-nonsense companion who helps you stay in the right mode, finish what you start, and protect your creative + rest time.

## Features

- **Modes**: Morning · Deep Work · Admin · Creative · Evening · Free
- Guided routines for Morning, Work, and Evening
- Quick capture + task lists per mode
- Voice chat with Enid (speak + listen)
- Local-first (works offline once loaded)

## Live

Once pushed to GitHub Pages this will be available at your chosen URL.

## Local use

Just open `index.html` (or `sidekick.html`) in a modern browser (Chrome recommended for voice).

## Notes

- Data is stored in the browser’s localStorage when available.
- Voice uses the browser’s built-in speech synthesis — pick your preferred voice from the dropdown in the Enid panel.
